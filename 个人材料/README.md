# 个人材料说明

每位成员需在本目录下提交：

1. `软件班级-姓名-个人报告.pdf`（或 .docx）：本人负责的需求分析、设计、代码与测试说明，以及成果位置；
2. `软件班级-姓名-工作证据/`：至少 1 项可定位证据，例如 Git 提交记录截图、合并请求、接口测试记录、
   测试报告、设计文档片段或验收截图。

个人报告建议结构见 `个人报告模板.md`，复制后重命名为 `软件班级-姓名-个人报告` 并导出 PDF。

注意：
- 不要放入含真实 API Key、真实个人隐私或与项目无关的文件；
- 证据中的截图应能对应到 `成员任务表.xlsx` 中的"成果位置"；
- 提交前确认个人报告与最终源码版本一致。
